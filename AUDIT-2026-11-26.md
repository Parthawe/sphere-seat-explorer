# Site audit · 26 November 2026

Reviewed F1 Tickets Online across the 47 published race guide pages, ten circuit-specific 3D scenes, and the Las Vegas entry points. This is a bounded implementation audit, not a guarantee that every defect or real-world seat mismatch has been identified.

## Fixed

- A malformed seat-view link for Qatar or another race could open Las Vegas. Venue-specific route guards now retain the requested race and explain unsupported views.
- Unknown race names silently displayed a season landing page. They now show a recovery link to the selected season’s calendar. Invalid seasons and screen names also receive explanations.
- Circuit model selections reset on refresh. Public bank, section, row, position and camera mode now remain in the URL. Shared links retain the selected camera mode and exclude unrelated private fields.
- Selected viewing areas reset on refresh in six ticket desks. The public area ID now stays in the URL, without adding pasted ticket text or changing a landing page into a race detail page.
- The circuit explorer home link always selected 2026. It now retains the model’s season.
- The Las Vegas “All races” button led to the Las Vegas guide. Its label now matches its destination.
- Three kinds of dialogs lacked accessible names. Model grids, photo references and Las Vegas dialogs now reference their headings. Interactive area-map SVGs use group semantics so their named selection buttons remain exposed.
- Area comparison/share buttons and race breadcrumbs had targets below 24px high. They now have a minimum 44px height; affected dialog close controls also have 44px targets.
- Malformed reference-price JSON could crash the ticket desk. Records are now validated, including dates, duplicate IDs, source URLs and reference prices. Failed loading offers a retry while area browsing stays available.
- Failed lazy-loaded application views could leave an empty page. A root recovery screen now offers reload and calendar navigation. Existing scene-specific WebGL fallback retains position controls.
- Generic grandstand guidance implied all grandstands assign chairs. It now describes a viewing area without promising an assigned seat.
- The Qatar introduction permanently described the event as “next race.” Its wording now distinguishes a race-weekend reference from a past-race reference.
- Fixed a missing space in generic race guidance and stale branding/default-entry descriptions in current project documentation.

## Validation

- All 47 race detail pages loaded at a phone viewport without uncaught errors, blank headings or horizontal page overflow during the initial scan.
- All ten circuit scenes rendered a canvas without falling back in the test browser. This does not certify performance on every GPU or device.
- Confirmed refresh retention for a Suzuka area and a Bahrain model row/camera; verified invalid-route recovery and named-grid keyboard dismissal.
- Confirmed 320px page fit across the six ticket workspaces, Las Vegas area explorer and a representative circuit explorer.
- Injected malformed price JSON: area browsing remained available; retry loaded the valid checked-in snapshot.
- Blocked a lazy scene-module request: the root recovery screen appeared.
- Disabled WebGL: the scene fallback appeared and model position inputs remained available.
- The mechanical UI detector returned no findings on the changed surfaces. This is not a full accessibility certification.
- Regression suite: 116 tests passed; TypeScript validation passed before packaging.
- Rechecked the official [2026 calendar](https://www.formula1.com/en/racing/2026) and [2027 calendar](https://www.formula1.com/en/racing/2027); the stored race lists matched the returned event dates.

## Remaining limits

Seat positions, row labels, structures and sightlines remain illustrative rather than venue-certified. Some race guides still have source information without a 3D reconstruction. Ticket stock, final prices and provider checkout remain external. This pass does not turn those stated coverage limits into supported features, and does not certify third-party availability, every external link, or every browser/device combination.

## Second pass · navigation and Sphere

The follow-up exercised complete journeys rather than repeating the first page-load scan.

Fixed:

- Calendar navigation previously landed above the calendar because asynchronous content changed its position. Same-page navigation now waits for the requested target, the loading placeholder and fonts; the target receives keyboard focus. Both the navigation action and direct calendar anchor were confirmed around the intended 24px scroll margin.
- Browser history could show one public area ID while six ticket desks retained another selection. Those desks now restore supported area IDs on history navigation, with venue/year checks and an explicit per-desk default.
- Sphere model positions and view settings reset on refresh. Level, section, row, seat, camera mode and all-level visibility now have bounded public URL fields, plus a copy-link control. Links exclude unrelated ticket and tracking fields.
- Sphere grid arrows were reversed relative to the drawing’s row direction. Down now moves to the next displayed row; up moves to the previous one.
- Las Vegas area comparisons disappeared after entering a seat view and returning. Supported area IDs now persist per season, with a clear action and a tab-only notice when storage is blocked.
- Interactive Las Vegas map markers were hidden beneath image semantics, and the flat fallback map lacked keyboard selection. Interactive maps now expose grouped, named buttons with selection states and visible focus feedback.
- An initial Sphere WebGL failure offered no retry. Its recovery flow now includes retry and retains the level/position controls and model grid. Retrying while WebGL remained disabled was verified.
- Canonical and sharing URL metadata could lag behind an in-place selection. A shared allowlist now updates the metadata after area, model or Sphere selection changes, excluding unrelated query fields.
- Sphere share/retry controls and the all-levels checkbox label have at least 44px target height. The Sphere workspace had no horizontal page overflow at 320px in the checked state.
- Las Vegas area search now ignores leading and trailing whitespace.

Validation: 119 regression tests passed, TypeScript validation passed, and the UI detector reported no findings on the changed surfaces. Confirmed a saved area after a seat-view round trip, clearing that comparison across refresh, a 400-level Sphere share/refresh round trip, metadata after history navigation, and keyboard selection with WebGL disabled. The limits listed above still apply.
