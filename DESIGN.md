# Viewpoint design direction

The user explicitly requested the F1 visual language and Las Vegas Grand Prix theme after rejecting the olive/gold release. Preserve the working selection, comparison, sharing and estimated-data boundaries. Replace the weak scene and visual treatment.

Use F1 red (#e10600), ink black (#15151e), white and neutral greys. Use the existing licensed Barlow Condensed in bold/italic for motorsport display and IBM Plex Sans for operational text. Use structured dividers, precise controls and limited cut corners. No imitation official F1 logo, unsupported affiliation or proprietary font distribution.

The interactive scene leads. Las Vegas at night requires a dark sky, bright track floodlights, visible metal grandstands, mesh fencing and a luminous Sphere. Original LED art uses red and white. Detailed procedural geometry remains illustrative, not a verified digital twin.

Mobile uses the scene above a collapsible bottom sheet, retaining access to its controls without a long page. Selection, camera mode and saved comparisons remain obvious. Controls use red for selected/action states; the map identifies rows and seats with readable labels.

Source references inspected 22 November 2026: formula1.com, f1lasvegasgp.com and the official 2026 Sphere-zone diagram. External seat photography informs visual construction only and is not bundled.

The user subsequently confirmed true 3D as the quality priority. Start at a seated perspective and keep overview available. Favor material depth, soft shadows and geographic legibility over repeated props. Use bundled CC0 scanned asphalt and inexpensive geometry for distant seating. The enlarged map supports precise selection. Generic spectators are scene illustration; all structural positions remain estimates.

The platform-research revision prioritizes choosing together, retaining context and comparing views. Use a compact 1–4 quantity control, show the selected camera seat for group previews, retain saved choices in the scene, and dock primary actions while controls scroll. Linked yaw/pitch controls use the same relative viewing direction across comparison cameras. This does not add inventory or verified photography. See PLATFORM-RESEARCH.md.

The calendar extension retains the same F1 visual system. The root opens the 2027 season, with explicit 2026/2027 navigation, a searchable chronological race list, and per-race ticket-category guidance. Use an actual render from the app as the Las Vegas feature image. Never reuse the Vegas scene for another circuit. Keep model coverage distinct from race-guide coverage. The complete seating grid shows all five modeled stands, then a numbered selected-stand grid with center aisle, fit and magnify controls. The Sphere uses its published exterior envelope and original amber face artwork; it is a ground-cut spherical cap rather than an elevated full ball. Seat framing includes the whole shell from the default modeled position.
